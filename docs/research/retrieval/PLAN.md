## 目标与范围

以《流浪地球》首批 9 例验证：用户要形成何种理解、当前可见上下文缺什么、该取哪个已读来源，以及检索是否补齐必要证据。案例见 [scenarios.json](scenarios.json)。R12、R14、R20、R25、R26、R21、R29 复用只读主金标；P01 为历史回顾与结构导航探索例；N01 为不应检索的决策负例。P01 已做 GPT-6 Luna 小范围只读核验，但建议存在内部不一致及角色归属问题，必要证据仍是实验假设，不自动改金标；模拟用户不能裁定金标。

## 实验阶梯

1. **采集与回放**：分开记录 `raw_user`、人工 `gold_rewrite`、Sol 问法 `sol_paraphrase`、真实工具参数 `agent_query`。已完成授权的 6 场景模型批次，获得 5 条实际 query 和 1 条真实无工具决策，原生回执验真并本地回放；不扫描真实聊天。详见 [MODEL_BATCH_2026_10_03.md](MODEL_BATCH_2026_10_03.md)。未检索是合法决策，按案例单独核验。
2. **稀疏路径**：复跑当前 bigram OR 实际路径，逐例标出 FTS5 与 Python 扫描回退；在隔离索引中做 jieba 索引端/查询端一致的 OR、AND、短语对照。首批与既有 29 例的两种 query 来源均已完成；精简词项组合留待具体坏例驱动。
3. **候选与排序**：同一 query、已读边界、Top K、证据预算下比较 FTS5、BGE-M3 与离线 RRF。已补固定的真 jieba OR＋Dense 等权／2:1 RRF 和实际装包回放；两种融合仍未改善原话装包联合覆盖。已追加全部 29 例的自动双问题分句与两路首位保留消融，结果未改善，详见 RESULT。下一步先验证保留主语、阶段和指代语境的查询改写；排序对照冻结相同候选池。后续仅在可用且获准的专用 reranker 条件下另做模型排序实验；不同候选池或回退路径单列，不归因于单一算法。
4. **解释性评审**：按证据充分、纠错正确、指代消歧、跨段因果和已读边界评最终回答；这一项需要单独授权的模型样本与人工复核，不能由召回指标替代。

## 后续推进与经历材料

1. **真实 query 链路（首批完成）**：使用主进程隔离回执接口收集 Luna 首次工具 query／无工具 skip。Sol 仅提供改写问法，逐例由本任务 Codex 核对目标一致性；这不替代人类文学标注。首批未发生结构导航工具调用，不能声称已验证这条路径，也不把其他工具调用误记为 skip。
2. **语境保留消融（缓存词项首包完成）**：已分开比较原话、实际 Agent query 与人工上界，完整问题词项和给定上文没有新增装包覆盖，R14 有首位退化。下一步明确主体／阶段／关系的可观察约束；新 query 的 Dense 重检索不在本包结果中。查询处理与排序各有自己的对照，不把收益全归因于融合。
3. **证据选择消融（首包完成）**：固定候选集合、2400 估算 token 预算和最多4单元，默认／前4／新增词项覆盖三规则均未解决 R25。下一步选择约束需能说明为何保护跨阶段材料，并审计全部开发例的损失。应用 packer 保持默认，新规则只在算法目录回放，单列成本。
4. **独立验证**：锁定规则后用新问法与新作品的人工标注测试集复验，避免反复针对现有 29 例调参。是否扩大样本与模型预算按小批结果决定。
5. **最终理解验收与交接**：在相同 Luna 设置下做基线与优化组的逐例回答对照，人工核对因果、记忆纠错、证据引用与拒答边界；覆盖、决策、解释和延迟同时成立后才建议应用线接入。

最终经历按“业务问题 → 可复现基线 → 分层定位 → 单因素假设 → 正负结果 → 独立验证 → 应用取舍”组织。现阶段能讲清楚稀疏回退、真融合无收益、候选命中但装包丢证据、朴素分句的退化，以及实际 Agent query 在 R25 补齐证据的观察。可讲版本见 [EXPERIENCE.md](EXPERIENCE.md)。独立测试与成对回答验收仍待开展，不能声称上线收益、真实用户提升或整体文学理解提升。
