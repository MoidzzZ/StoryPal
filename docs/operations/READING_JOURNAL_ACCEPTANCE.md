更新：2026-10-03。预计5～8分钟，在《流浪地球》真实已读范围进行，不为测试把未读标已读。后台独立复核尚未实现，此轮仅测试工具维护与回看候选。

1. 已确认当前位置后输入：“把这个问题记到《流浪地球》的阅读手账：我想看看老师接下来会不会改变他的立场。”预期调用save_journal_entry新增question；不写Note、不推进进度。
2. 输入：“看看刚才记的那个问题。”预期从手账查出原观点和记录位置，不当剧情事实。
3. 输入：“把刚才那条问题改成：我更想关注他的理由有没有变化。请更新手账。”预期先确定唯一条目，revise引用本轮原话，原内容仍作为旧版本保留；不编造后续结果。
4. 输入：“删掉刚才那条手账，不用再留这条问题。”预期delete，随后查询无此条；AI不能承诺删除了所有旧聊天／摘要。别要求清空其他条目。
5. 可选真实继续阅读：另存一条自己实际关心的预测，正常读到下个完整单元并从阅读器标记、确认；下一轮聊相关人物。预期有机会自然承接旧疑问，但不能“无证据就宣布预测对了”。首次启用先建立基线、段内位置不触发，候选有上限；没有主动提起也不证明丢失，可以主动问“我之前那个预测现在怎么看”。
6. 情绪负例：“先别回看预测，刚才那段我还想缓缓。”预期接住感受，不因候选而硬拉去检索或修改手账。

请反馈：是否改对目标、有没有偷换原观点、回看是否恰好有帮助，以及删除范围有没有误导。程序已测owner／作品／重置边界与重复请求，不要求你反复操作正式进度或扮演其他用户。
