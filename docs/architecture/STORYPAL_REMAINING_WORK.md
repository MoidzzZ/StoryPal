## 2. 近期核心工作：两条线共享场景

2026-10-03 用户决定拆成独立会话：本会话推进应用功能，检索算法在新会话推进。职责、实验场景与文件边界见 [双线推进契约](STORYPAL_PARALLEL_TRACKS.md)；算法线不再阻塞 M3。

### R1：真实查询与检索对照（独立检索会话）

- 先补真实 Agent 发出的 query 采集／离线回放，关联用户问题、已读边界、工具与必要证据集合；保留 raw_user 和人工 gold_rewrite 作参照，不混淆效果归因。
- 隔离Hook／落盘收据／只读导出已完成，23项导出测试及受影响67项通过；不自动采正式聊天，真实故事agent_query仍0。见[导出规范](../operations/AGENT_QUERY_CAPTURE.md)。29例原话／人工改写、固定纯jieba融合和朴素分句已离线复跑，不改生产默认；具体取舍见[采纳记录](RETRIEVAL_FINDINGS_ADOPTION.md)。
- 先核验现有中文 bigram／查询组合，再比较 jieba 分词与 OR／AND／短语策略；避免只换库就认定改进。先跑小规模 bad cases，再跑现有 29 条同边界对照。
- 在相同候选和预算下比较 FTS5、BGE-M3、RRF；之后加入一个 reranker，必要时再比较另一种 Embedding。模型能否加载及下载状态另行核验，不把规划当实测。
- 输出证据覆盖、必要证据集合召回、排序、无结果／越界和耗时；最终理解贡献另评，不用单 chunk 命中冒充跨段推理成功。
- 不新增独立 Query Analyzer／Router 模型调用。真实请求前单独说明样本及发送范围；普通离线实现和回放不发送原文。

### M3：真正的跨会话互动经历（功能线）

M3-A事实源／M3-B联合压缩后抽取／M3-C语义回忆均已接通。已完成1条独立授权合成小样：真实Luna抽取1条经历，空白新会话主动回忆，匹配0.790002；保留用户质疑铺垫与检索失败未查清。水位手动归档，不包含自动压缩生成，尚无长聊／含糊指代／难负例阈值验收。76项既有程序回归与本轮67项有重叠，不相加。见 [M3 契约](STORYPAL_EPISODIC_MEMORY.md) 和根result。下一功能包是Note临时项／开放观察低频维护，再补手账编辑与旧预测回看；不回扫真实旧会话。

- 在 Checkpoint 压缩边界，从稳定对话抽取有情境、变化和后续意义的经历，写 `memory/YYYY-MM-DD.md`，保留时间、owner、原消息／证据引用和抽取水位；失败不丢原始历史，重复归档不重复写。
- Markdown 为事实源，BGE-M3／LanceDB 是可重建索引。先做单一语义阈值和 Token 预算，不加时间路由、复杂 Gate、MMR 或多轮搜索。
- 主 Agent 需要回忆时调用一个工具；少量自动相关注入是否必要，由跨会话用例验证。无结果不是“从未发生”，用户经历也不是故事事实。
- 工具 Observation 仅在改变理解、查证结论或保留未解问题时进入经历；失败／重试不逐条长期保存。
- 按用户决定，`MEMORY.md` 暂缓。Note、手账和经历不互相自动双写；旧 HistoryMemory 兼容迁移另验。

### Q1：陪读业务验收（贯穿两条线）

- 先在《流浪地球》少量已读场景验证“够用不检索、缺口补正确来源、澄清后继续”；再核验人物、因果和叙事解读是否有新增帮助，不替作品圆场。
- 新摘要对“纠错／澄清”的提示已加强，实际生成效果仍未复核。中文迭代预算／异常兜底仍待补，不用完整鲁棒性工程阻塞功能。
- 开发侧数据核验用 GPT-6 Luna；模拟用户用 GPT-6 Sol；真人只需判断首句抓点、观点承接与理解增量。模拟不裁定唯一文学金标。
- 工具数量、实际输入 tokens、延迟及缓存用真实记录核算；现有 ContextPacker 只预算正文／摘要及新增名称元数据，尚不是完整工具 JSON 的总预算。
